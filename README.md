# TallyDock support

For help with the offline warehouse app on iPhone or iPad, visit the support page in your language.

- [English](https://tallydock-support.www-rsa920.chatgpt.site/en/)
- [Polski](https://tallydock-support.www-rsa920.chatgpt.site/pl/)
- [Русский](https://tallydock-support.www-rsa920.chatgpt.site/ru/)

To report a problem, open an issue with the app version, iOS or iPadOS version, device model, what you expected and what happened. Issues are public. Use fictional product examples and keep personal details and warehouse files private.
